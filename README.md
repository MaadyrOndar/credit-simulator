# Гибкий Кредитный Симулятор

> 🌐 **Онлайн-версия:** [Запустить Гибкий Кредитный Симулятор](https://maadyrondar.github.io/credit-simulator/)

Интерактивный браузерный калькулятор для расчёта кредита и планирования досрочного погашения. Позволяет наглядно оценить переплату по процентам, сравнить стратегии досрочных платежей и заглянуть в помесячный график выплат.

Работает локально в одном HTML-файле без установки программ, регистрации и передачи финансовых данных на сторонние серверы.

## Основные возможности

* **Гибкая настройка кредита:** расчёт на основе текущего остатка долга, процентной ставки (% годовых) и оставшегося срока в месяцах — удобно для анализа как нового, так и уже действующего кредита.
* **Две стратегии досрочного погашения:**
  * **Сокращать СРОК кредита** — позволяет максимально уменьшить итоговую переплату по процентам.
  * **Сокращать РАЗМЕР платежа** — снижает ежемесячную финансовую нагрузку.
* **Наглядная сводка выгоды:** мгновенный расчёт базового платежа банка, итоговой экономии на процентах и количества сэкономленных месяцев.
* **Помесячный симулятор («Заглянуть вперёд»):** подробная таблица по каждому месяцу с разбивкой платежа на проценты, погашение основного долга («тело» кредита), регулярную досрочку и остаток задолженности.
* **Удобное форматирование (Авто-пробелы):** автоматическое разделение разрядов чисел пробелами (например, `143 145,99`) при вводе и расчётах для лёгкого чтения сумм.
* **Встроенные подсказки (`?`):** интерактивные пояснения ко всем полям ввода, стратегиям и колонкам графика.

## Как пользоваться

1. **Онлайн:** откройте симулятор по ссылке на GitHub Pages.
2. **Локально на компьютере:** скачайте файл `index.html` и откройте его двойным кликом в любом современном браузере (Chrome, Firefox, Edge, Safari).
3. Укажите параметры вашего кредита и сумму планируемой регулярной досрочки — расчёты и таблица обновятся автоматически.
